# DCEAY Music Web Player

A modern, high-performance cyberpunk music streaming web player featuring synchronized karaoke lyrics, iTunes Search API, customizable playlists, play queue, and high-definition album art.

## Features
- **Curated Global & Khmer Viral Hits**: Immediate streaming for popular hits with synchronized karaoke lyrics.
- **Full Edge-to-Edge HD Album Artwork**: 1:1 squircle artwork display with zero letterboxing or black bars.
- **Live Synchronized Lyrics Engine**: Accurate millisecond-level karaoke sync for songs.
- **iTunes Search Integration**: Discover and preview millions of songs with 600x600 HD artwork directly from the Apple iTunes catalog.
- **Custom Playlists & Play Queue**: Create playlists, reorder, shuffle, and manage your playback queue.
- **Playback Controls**: Speed controller (0.75x - 2.0x), Sleep Timer with soft audio fade-out, Fullscreen mode.
- **Glassmorphism & Cyberpunk Themes**: Aesthetic UI themes crafted with pure modern HTML5, CSS3, and vanilla JavaScript.

## Deployment
Can be deployed directly to **GitHub Pages**:
1. Go to repository **Settings** > **Pages**
2. Under **Build and deployment**, select `Deploy from a branch`
3. Choose branch `main` and root `/`
4. Save and visit your live music player URL!
